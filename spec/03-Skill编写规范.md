# 03 · Skill 编写规范

Skill 是**按需加载的能力包**：一个文件夹封装一类可复用任务的完整做法。
格式完全遵循 [Agent Skills 开放标准](https://agentskills.io)。

## 1. 与 AGENTS.md 的分工

| | AGENTS.md | SKILL.md |
|---|---|---|
| 加载时机 | 每次会话开机必读 | 命中任务时按需加载 |
| 内容性质 | 人设、边界、总流程 | 某类任务的操作规程 |
| 判断标准 | "不写这个，agent 每次开机都会跑偏" | "遇到这类任务才需要" |

【必须】流程一旦具备"可命名、可复用、有固定步骤"三特征，即抽为 skill，
从 AGENTS.md 中移出。

## 2. 目录结构

```
skills/<技能名>/
├── SKILL.md          # 必须：元数据 + 指令
├── scripts/          # 可选：该技能专用的确定性脚本
└── references/       # 可选：参考资料、范例
```

【必须】技能名用小写连字符英文（`weekly-report`），SKILL.md 内可用中文。
【应当】一个技能一个意图；超过 300 行的 SKILL.md 应回收为多个技能。

## 3. SKILL.md 模板

```markdown
---
name: weekly-report
description: 把素材/周报/ 下的原始记录加工成周报初稿。
  当用户要求"写周报""汇总本周记录"时使用。
---

# 周报导写

## 输入
素材/周报/ 下当周的全部 .md 文件（命名 YYYY-MM-DD-主题.md）。

## 步骤
1. 按日期排序读取全部记录
2. 按素材自带的分类归并条目，同类合并、保留原始出处
3. 生成 产出/周报/YYYY-Www-周报.md（模板见 references/tpl.md）
4. 运行 python scripts/check_report.py 校验章节完整性
5. 校验不通过则修复后重跑，禁止跳过校验宣告完成

## 边界
- 不虚构台账中不存在的进度
- 引用原句必须出自素材，禁止改写数字
```

【必须】`description` 写清**触发条件**（什么时候用），这是模型检索技能的
唯一线索；含糊的 description 会让技能永远不被选中。

## 4. 渐进披露原则

- 【必须】SKILL.md 正文只放"执行本任务必需"的指令；
- 【应当】长范例、背景资料放 `references/`，正文用一句话指路；
- 【可以】技能间可互相引用（"先执行 `init-project` 技能"），但禁止循环。

## 5. 生命周期

1. **沉淀触发**：同一流程被手工指导模型 ≥2 次后，必须沉淀为 skill；
2. **评审**：新技能入库前跑一次真实任务验证 description 命中率；
3. **退役**：流程变更时更新 SKILL.md 并在文末注明修订，而不是新建平行技能。

## 6. 反模式

- ❌ description 写成名字复读（"weekly-report：用于周报"——没说何时触发）
- ❌ 把一次性任务包装成技能
- ❌ 技能内嵌大段需逐字执行的提示词（应改为步骤化指令）
- ❌ 同一流程在 AGENTS.md 和 SKILL.md 各写一份
