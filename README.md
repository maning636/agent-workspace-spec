# 智能体工作区开发规范

> 仓库名 `agent-workspace-spec`（智能体规范开发规范）· 评审版 v0.1 · 2026-10

一份可落地的中文规范，定义如何把一个普通文件夹组织成**专有 AI 智能体**：
CLI 是运行时，文件夹是岗位说明书 + 工具箱 + 记忆体。任何支持 AGENTS.md /
Skills 的编码 CLI（Claude Code、Codex、Kimi Code、OpenCode 等）进入这个
文件夹，即获得一致的人设、能力与产出纪律。

**本规范不发明新标准**，只做两件事：

1. 引用并衔接两个已成文的开放标准：[AGENTS.md](https://agents.md)（项目约定）与
   [Agent Skills](https://agentskills.io)（能力封装）；
2. 在两者之上补齐中文工程实践缺口：目录分区、台账（跨会话状态）、
   确定性脚本纪律、多 CLI 协作边界。

## 适用场景

- 单人或小团队，用 2-3 个 agent CLI 干活，希望行为稳定可复现；
- 任务多为"对话驱动、产物落盘"型（写稿、审校、调研、批量处理）；
- 想先不引入看板/调度平台，就把 agent 的工作流管起来。

**不适用**：需要无人值守定时调度、多机器并行、自动重试的场景——
那是调度层（如 Multica、自建 daemon）的职责，见 `spec/07-多CLI协作.md`。

## 快速开始

```bash
# 1. 复制模板作为新工作区
cp -r templates/workspace/ 我的智能体/
# 2. 填 AGENTS.md 的身份与工作流
# 3. 第一个技能放进 skills/<技能名>/SKILL.md
# 4. 用你的 CLI 打开该目录即可开工
```
