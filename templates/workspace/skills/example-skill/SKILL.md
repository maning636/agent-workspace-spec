# 示例：素材归档

> 复制本文件夹作为新技能的起点；SKILL.md 正文只保留本技能执行的步骤。

## 输入
- `素材/收件箱/` 下所有 `.md` 文件

## 步骤
1. 按文件内首行标题生成新文件名：`YYYY-MM-DD-主题.md`（日期取自文件内容，
   取不到时用文件修改日期）
2. 移动到 `素材/已归档/`（目标目录不存在时先创建）
3. 运行 `python scripts/check_archive.py` 校验无遗留未命名文件
4. 在 `台账.md` 的"已完成"登记归档数量

## 边界
- 只移动、重命名，不修改文件内容
- 同名冲突时追加 `-2` 后缀，不覆盖
