# 示例：收件箱归档

> 本文件是 03 篇推荐写法（Use When 四段式）的**可跑业务示例**；
> 新建技能优先按本结构写，不要用"输入/步骤/边界"的简化旧式。

## Use When
- 用户要求"整理收件箱""归档素材"
- `素材/收件箱/` 存在未按 `YYYY-MM-DD-主题.md` 命名的 `.md` 文件

## Don't Use When
- 需要修改文件内容 → 归档不改动内容，改动在会话中单独处理
- 非 `.md` 文件 → 人工判断后手动处理
- 目标不是归档而是加工成产出 → 改用对应的产出类技能

## Workflow
1. 读取 `素材/收件箱/` 下每个 `.md` 的首行标题与内容日期
2. 生成新文件名 `YYYY-MM-DD-主题.md`（取不到内容日期时用文件修改日期）
3. 移动到 `素材/已归档/`（目录不存在先创建；同名冲突追加 `-2`，不覆盖）
4. 运行 `python scripts/check_archive.py`（待实现）校验收件箱已清空
5. 在 `台账.md` 的"已完成"登记归档数量

## Rules
- Always 只移动、重命名，不改一个字（Why: 素材必须可溯源）
- Never 覆盖 `素材/已归档/` 中同名文件（Why: 防丢历史）
- Never 触碰 `素材/收件箱/` 之外的文件（Why: 边界最小化）
